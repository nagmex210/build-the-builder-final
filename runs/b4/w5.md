# b4 w5: submission engineer (branch harness/submit)

No change to how the builder builds the phone agent. All edits are about running, tracing, exporting and scrubbing.

- `builder/build.py` (additive): stdout/stderr wrapped by `btb/scrub.Redacting`; printed trace = `BUILD START/END`
  (UTC), `[model call]` line per Azure call (thread tailing the jsonl, catches every process that uses btb/llm.py)
  and per Claude Agent SDK message (model + tools), Bash results of the build agent (400 chars), `[test] datecalc`,
  lint, `[freya]` slot/workflow_id/agent_id/version, export to `submission/<slot>.workflow.json` (json-checked,
  path printed), jsonl trace scrubbed at the end. Last line still `{"workflow_id", "agent_id"}`.
- `builder/save.py`: flock around `freya.save_workflow` so two parallel builds don't lose a slot in `.freya-agents.json`.
- `btb/scrub.py <files...>`: in-place redaction (env key values, JWT, sk-, fak_).
- `btb/submit.sh <brief.md> <tool_api.json> [name]`: keys from env or SSM, build (tee `traces/<name>.log`), export
  (fallback re-export), scrub, key check, summary; exit != 0 on failure. Works from any cwd.
- `.gitignore`: `submission/`, `traces/`, the lock file.
- `FINAL.md`: Sunday checklist (freeze, briefs, parallel runs, verify, allowed post-17:00 fixes, key rotation,
  remove the Builder login line at the freeze, open question on "one commit").
- Rehearsal (brief C + raw A in parallel, one from /tmp with relative paths): both exit 0 in ~185 s, exports load,
  no key in any file. Details: `runs/submit_rehearsal.md`.
