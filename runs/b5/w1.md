# b5 worker 1: close in structure, not in the model's head

Start: main (= merge/b4, 779b267). Branch idea/b5-1.

## Idea

On official raw runs (b4 rA4 PUB-01/05, rB PUB-11) and in b1/b2 logs, the model said the goodbye as text without
calling close_call. The customer said goodbye, the platform's goodbye auto-trigger (`end_call`, source
`auto_trigger`) hung up, and no outcome was recorded ("the call was not closed with close_call"). A3 (canned.py) made
this worse: the close tool's description said "before calling, say exactly <goodbye>", so the goodbye was spoken
before the outcome existed.

Fix it in structure: the goodbye can only be spoken by the platform AFTER close_call returned ok, and the model is
told never to say goodbye itself, so neither side triggers the goodbye hang-up before the outcome is recorded.

## What changed (files)

- `builder/canned.py`: new `close_structure(wf, canned)`, run in the final deterministic pass (`apply`, called by
  `save.finish_and_save`, also when no canned spec exists; idempotent):
  - every end_call node that a close-tool transition routes to gets `message_mode: custom`,
    `spoken_message: <the brief's goodbye>` (A3 extraction; fallback "Thank you for your time. Goodbye."),
    `on_enter: silent`;
  - close -> hang-up conditions: any `<close>_success_count` condition is dropped (M19: a guard's blocked close is a
    2xx too); if nothing is left, the ok == true/True pair is used;
  - "say (the) goodbye (then close)" phrases in task messages, the system prompt and the close tool description are
    removed at PHRASE level (a whole-sentence filter first deleted the "customer has died: say exactly ..." line: a
    sentence can carry a mandatory line and a close reason, so only the goodbye words go);
  - a `CLOSING (overrides ...)` rule is appended to each conversation node that has the close tool and to the system
    prompt: never say goodbye/bye/closing thank-you; when done call the close tool (notes/transfer first); if the
    customer says goodbye, call it in that same turn;
  - the close tool's description starts with "Call this to end the call, INSTEAD of saying goodbye ...". The goodbye
    text is deliberately NOT quoted to the model: in the first build the description quoted it and the model said it
    too (double goodbye, M10: quoted text is said word for word). The FIXED SENTENCES goodbye line now says "not yours".
  - the old A3 "Before you call this, say exactly <goodbye>" on the close tool is gone.
- `builder/selftest.py`: `hang_up_events(call_id)` reads the call's system events (end_call, goodbye auto_trigger,
  call_ended) before the harness ends the chat (waits 4 s when the ledger has no close yet); a persona whose call
  was hung up without close_call fails with "the call was hung up (...) without close_call: no outcome was recorded".
  The row keeps `hang_up` in the trace.
- `.claude/skills/build-phone-agent/routing.md`: hang_up node pattern = custom spoken_message; close -> hang-up
  routes on `ok` only (success_count pattern removed); node preamble "Never say goodbye yourself: ... the system says
  the goodbye" (so the inner Claude builds it that way before the pass).

## Root cause found on the way (not fixed here: hypothesis for the next batch)

The exported workflow carries the platform's DEFAULT `agent_config.llmConfig` (we omit agent_config, the platform fills
it): a built-in `end_call` tool and the system prompt "You can use `end_call` tool after you say goodbye to customer to
hang up if call about to finish". So a goodbye said by the model invites the platform's own end_call, which hangs up
outside our workflow, with no close_call. This is the "end_call ... source auto_trigger" path. Removing the model's
goodbye (this branch) takes away the trigger. (H) Overriding `llmConfig.tools: []` and that systemPrompt (model left
unchanged) would remove the path entirely; untested, and lint_workflow.py currently errors on any agent_config.

## Brief-agnostic?

Yes. Nothing is read from brief A/B: the goodbye text comes from the A3 extraction of whatever brief is given (generic
fallback), the close tool and end node are found by structure (the close-tool transition into an end_call node), the
rewrite patterns are English phrasing of "say goodbye then close" that the inner builder writes for any brief, and the
self-sim check reads platform events. Risk: a brief whose required goodbye differs per outcome gets one goodbye
(the one A3 extracted); a brief that makes a farewell sentence mandatory gets it verbatim from the platform.
